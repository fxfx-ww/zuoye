📚 Agent 概念深度教学方案

Agent（智能体）

基于黑格尔《逻辑学》概念论「普遍性 → 特殊性 → 个体性」三环节

让学习者从"记住名词"走向"能独立判断 + 推理"

① 概念理解诊断报告

核心概念
Agent（智能体）
所属领域
人工智能 / 计算机科学
适用学段
高中 / 大学通识
课时
90 分钟

诊断依据

初学者典型表现：听过 ChatGPT、智能客服、扫地机器人这些"会做事的程序"，把它们笼统称为"AI"；能背"Agent = 智能体 = 能自主行动的AI"，但在新情境下（恒温器是Agent吗？会写诗的LLM是Agent吗？）无法做出有依据的判断。

┌──────────────────────────────────────┐ │ Agent │ ├──────────────────────────────────────┤ │ 当前层次：存在论层（知道有，会背定义） │ │ 目标层次：概念论层（独立判断+推理） │ │ 差距：从"记住"→"区分"→"判断" 三层跃迁 │ └──────────────────────────────────────┘

层次诊断详析

层次能回答的不能回答的
存在论层（记忆） "什么是Agent？" → "能自主行动的AI" Agent和普通程序、和大模型有什么区别？
本质论层（关系） 已建立关系：AI、机器人、自动化 混淆 Agent vs ChatBot / 单一AI模型
概念论层（运用） 知道 ChatGPT、扫地机器人常被叫 Agent 恒温器是Agent吗？LLM是Agent吗？
🎯 核心问题诊断

"影子"：把 Agent 当成"高级一点的程序"，忽略"感知-思考-行动"闭环、自主性、目标导向这三个本质特征。

"突破口"：用 感知思考行动 三要素作为抓手，让学生从"会做事的程序"中识别 Agent，再用"自主性 / 目标性 / 适应性"三维判断其类型。

② 概念深度教学设计方案

第一重：普遍性——提炼共同本质（约25分钟）

教学目标：学生能从多个具体事例中，自己"发现" Agent 的共同本质——感知 → 决策 → 行动 的闭环系统

环节教师活动学生活动设计意图
呈现多样事例 展示4个例子：扫地机器人 / 自动驾驶 / ChatGPT+工具调用 / AlphaGo 观察每个系统的输入和输出 丰富感性基础
引导比较 提问"这4个'智能系统'有什么共同的'动作模式'？" 分组讨论，列异同 为抽象做准备
提炼本质 引导学生归纳"感知环境→思考决策→采取行动→影响环境" 尝试用一句话描述 Agent 的"骨架" 完成第一次抽象
这一步不给定义，而是让学生从4个具体例子中自己看到共同模式。

第二重：特殊性——展开内在分化（约30分钟）

教学目标：学生理解 Agent 不是"铁板一块"，而是按自主性和内部复杂度分为多种类型

类型表现适用情境智能"增量"
①简单反射型 当前感知 → 立即行动（if-then） 环境完全可预测（恒温器、自动门） 决策深度=0
②基于模型型 维护内部世界模型 → 推断状态 → 行动 环境部分可观测（扫地机器人记忆已清扫区） 引入"记忆"
③目标驱动型 规划"如何达到目标" → 行动 需要多步达成目标（GPS导航） 引入"规划"
④效用驱动型 在多个目标间选择"最优" → 行动 目标冲突（自动驾驶平衡速度与安全） 引入"权衡"
⑤学习型 Agent 通过反馈改进决策 → 行动 环境未知且会变化（AlphaGo） 引入"自进化"

第三重：个体性——创造性地运用（约25分钟）

教学目标：学生面对从未见过的新情境，能独立判断"这个系统算不算 Agent？是哪种类型？"

任务1（识别型）
恒温器——温度高于26℃就开空调，低于24℃就关。它是 Agent 吗？
任务2（论证型）
会写诗的 LLM——能写诗，但不能联网、不能记住之前的对话、不能调用工具。它是 Agent 吗？
任务3（分类型）
特斯拉 FSD 自动驾驶系统，应该归为哪一类 Agent？为什么？
任务4（创造型）
请你设计一个 Agent 解决"图书馆找书"问题。要求：明确它的感知、决策、行动分别是什么。

③ 判断与推理训练设计

判断四层次递进

"恒温器算Agent，但只是最简反射型"

三段论还原训练

范例

老师说："恒温器是 Agent"，请还原推理结构：

大前提：所有具有"感知-决策-行动"闭环的系统都是 Agent
小前提：恒温器能感知温度、决定开关、采取行动
结论：所以恒温器是 Agent

反例推理训练

🤔 假设 Agent 概念不存在……

那么：

  • AI领域会怎样？（失去"具身智能"主线，强化学习不会诞生）
  • 扫地机器人会变成什么？（变成"被遥控的吸尘器"）
  • 哲学上的"行动者"概念会怎样？（失去计算机科学对应物）

→ 反推让学习者明白：Agent 是连接算法与真实世界的关键桥梁。
